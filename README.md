# TrackViewer

TrackViewer — веб-приложение для просмотра и организации GPS-треков из разных источников.

Базовая цепочка продукта:

```text
геоданные → рабочая область → карта → действия пользователя
```

## Текущий scope

Входит: библиотека источников и треков, локальные GPX/XML-файлы, интеграция с Komoot, карта, базовые характеристики трека, управление отображением, GPX-экспорт.

Не входит сейчас: аккаунты TrackViewer, серверное хранение пользовательских треков, синхронизация между устройствами, FIT/TCX, пакетная обработка, редактирование геометрии, автоматические решения об изменении трека.
