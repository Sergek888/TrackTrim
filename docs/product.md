# Product

## Name

TrackTrim

## Description

TrackTrim — веб-приложение для анализа и интеллектуальной обрезки GPS-треков.

Основной сценарий:

Пользователь закончил поход, забыл остановить запись, затем сел в автомобиль.

Приложение анализирует трек, предлагает точку обрезки и выполняет изменение только после подтверждения пользователя.

## Goal

Создать простой инструмент для исправления GPS-треков без ручного редактирования в GIS-программах.

Файлы должны обрабатываться локально.

## User scenarios

### Сценарий 1

Пользователь:

1. загружает GPX
2. приложение анализирует трек
3. приложение предлагает обрезку
4. пользователь подтверждает
5. создаётся новый файл

### Сценарий 2

Если перед автомобилем была длительная остановка:

предлагать обрезку с начала остановки

### Сценарий 3

Если уверенности недостаточно:

не выполнять автоматическую обрезку

## Domain rules

- трек состоит из последовательности точек
- скорость вычисляется между точками
- быстрый хвост может быть автомобильным
- GPS-шум не должен считаться автомобилем
- изменения без подтверждения запрещены

## MVP

Входит:

- загрузка одного GPX
- анализ трека
- предложение точки обрезки
- подтверждение
- сохранение нового GPX

## Constraints

- без backend
- без отправки файлов
- исходный файл не менять

## Not included

- карты
- графики
- пакетная обработка
- FIT
- TCX
- интеграции
