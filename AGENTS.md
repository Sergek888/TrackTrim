# Agent instructions

Перед началом работы прочитай:
- docs/product.md
- docs/architecture.md
- docs/roadmap.md

Правила работы:

- делай минимальные изменения;
- не переписывай проект целиком;
- сохраняй текущую архитектуру;
- не меняй структуру проекта без необходимости;
- не изменяй код вне текущей задачи;
- сначала анализируй;
- потом предлагай изменения;
- объясняй затронутые файлы;
- после изменений кратко объясняй результат;
- не создавать новые абстракции без причины;
- не добавлять зависимости без необходимости;
- если требования неоднозначны:
    - сначала перечислить варианты;
    - объяснить компромиссы;
    - не угадывать.

При изменении проекта:

1. Опиши:
    - какие файлы будут изменены;
    - зачем;
    - что останется нетронутым.

2. Выполни изменения.

3. Кратко объясни результат.
